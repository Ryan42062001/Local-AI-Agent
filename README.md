# Local AI Agent

Local AI Agent is a standalone project repository for local-first AI agent experimentation and development.

## Status

This repository is currently a project shell. No application code has been committed yet.

## Repository boundaries

This project is independent from:

- **The War Room** — fantasy football draft-day assistant
- **The Chip Winner** — in-season fantasy football decision companion
- **Family Finance Hub** — household financial planning application
- **Everett Church of God Website** — church website replacement project

Code, issues, branches, deployment settings, and documentation for those products should remain in their own repositories.

## Development convention

- `main` is the stable branch.
- New implementation work should use short-lived feature branches and pull requests.
- Delete feature branches after they are merged or intentionally abandoned.
- Add setup, architecture, testing, and deployment documentation here when implementation begins.
